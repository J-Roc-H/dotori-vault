# Working guide - writing

## Before drafting

Read the feedback log for this form. Recurring corrections live there, and re-making a
correction you already received is the most common failure in this domain.

## Review before calling a draft done

- Read it aloud once. Sentences that stall are the ones to cut
- Check that every claim the narrative depends on was actually established earlier
