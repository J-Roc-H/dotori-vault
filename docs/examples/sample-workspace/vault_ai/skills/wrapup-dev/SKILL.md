# Session wrap-up

1. **Log it.** Append to the project log: what changed, what was verified, what was not
2. **Distil.** Anything learned that will apply again goes to the domain core, not the log
3. **Budget check.** If a guide grew past its line budget, move the overflow down a layer
4. **Leave the code folder clean.** Notes belong in the vault, not next to the source
